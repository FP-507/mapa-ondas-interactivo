# Las ondas que mueven nuestro mundo · Mapa mental interactivo

Mapa mental interactivo basado en el ensayo reflexivo *Tecnologías de ondas*. Cada idea está conectada por ondas animadas y cada rama incluye un experimento: espectro electromagnético, AM/FM, radar, fibra óptica, sonar, medidor de decibeles y más.

## Ver en línea
Abre la página publicada en GitHub Pages (enlace en la descripción del repositorio).

## Ver en tu computadora
```bash
node server.js
```
Luego abre http://localhost:5173. También puedes abrir `index.html` directamente en el navegador.
